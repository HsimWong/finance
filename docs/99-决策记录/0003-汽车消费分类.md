# ADR 0003 · 汽车消费独立成一级分类

- 日期：2026-11-13
- 状态：已采纳并上线（结构版本 v1 → v2）
- 触发：用户要求「增加汽车消费的保养、保险、维修类别」

## 背景

v1 分类树是两级结构，用车相关的支出散在两处：

- `交通` › 公交地铁、打车、**加油**、**停车费**
- `保险` › **车险**、人身险、财产险

结果「这辆车一年花了多少」无法一次查出：加油/停车在交通，车险在保险，保养维修根本没有位置。用户现在要保养、保险、维修三个类别，如果只往现有节点下面塞三个叶子，问题依然存在（三类分散、口径不统一）。

## 决策

新增一级领域 `汽车`，作为「自家用车」的唯一归口：

```
汽车 ›  加油 · 停车费 · 保养 · 维修 · 保险
交通 ›  公交地铁 · 打车          ← 只剩公共交通与打车
保险 ›  人身险 · 财产险          ← 只剩人身/财产保险
```

迁移方式（`src/backend/backup.go` 的 `migrations[2]`）：

| 动作 | 方式 | 为什么这样做 |
| --- | --- | --- |
| 新增 `汽车` 一级分类 | INSERT，位置插在 `交通` 之后 | 与「交通」相邻，设置页里看着顺 |
| `加油`、`停车费` 从交通迁入汽车 | **改 `parent_id`，不改 id** | id 不变 → 历史流水的 `category_id` 全部有效，不会出现"分类被删、流水变未分类" |
| `车险` 迁入汽车并更名为 `保险` | 同上 | 保留 id；挂在汽车下叫「车险」冗余，叫「保险」符合用户表述 |
| 新增 `保养`、`维修` | INSERT | 用户本次要求 |
| 所有语句带存在性判断 | `WHERE NOT EXISTS` | 重复执行不产生重复分类（已有幂等测试） |

配套改动：

1. **同名分类解析**：`findCategoryID` 改为优先「叶子分类」（没有子分类的那个）。否则「保险」会命中一级 `保险`，导致车险账单归错。现在 `保险` → `汽车›保险`，`囤货采购` 这类本身是唯一匹配的仍命中自己。
2. **OCR 商户规则**：汽车规则排在「交通出行」之前，并把 `加油`/`停车` 从打车规则里移除，否则永远被当成打车。维修规则排在保养之前——「汽车维修」「更换刹车片」不能落到保养。
3. **种子数据同步**：新库的 `seedCategories` 直接是 v2 结构，`TestFreshDBHasCarCategories` 保证「全新库」与「升级库」结果一致。

## 放弃的方案

- **`交通›汽车›保养` 三级嵌套**：递归查询能算，但分类下拉只渲染两级（`optgroup` + 一级选项），三级会显示不出来；也没必要为了层级把汽车藏在交通下面。
- **只加三个叶子不动结构**：改动最小，但「汽车总支出」仍然查不出来，与用户提这个需求的初衷相悖。
- **保留 `车险` 名称不重命名**：可以避免同名，但用户明确说的是「保险」类别；同名带来的歧义改用「叶子优先」规则解决，比让用户记两个近义名词更好。

## 后果与风险

- 一级 `保险` 从此只覆盖人身险/财产险；习惯在「保险」下找车险的话，现在要去「汽车 › 保险」。已在 README 与本文记录。
- `保险` 这个名字在树里出现两次（一级 + 汽车下），下拉框靠 `optgroup` 与「（一级）」后缀区分；程序侧靠「叶子优先」消歧。
- 分类总数 55 → 58，`user_version` 1 → 2。升级前必定备份（`*_before-migration-v2.db`），失败即中止启动，不会带着真实数据冒险。
- 如果用户今后在设置页手工改名/删过分类，迁移语句的存在性判断会跳过已存在的项，不会重复插入。

## 验证

`go test`（含新增 2 项）与真实库升级实测：

- `TestMigrationV2CarCategories`：造一个 v1 结构库（旧树 + 一条挂在「加油」上的流水）→ 跑正常启动流程 → 断言分类树正确、`user_version=2`、升级前有 `before-migration-v2` 备份、**历史流水的 `category_id` 未变且已落在 `汽车›加油`**、重复迁移不产生重复分类。
- `TestFreshDBHasCarCategories`：全新库直接初始化得到同样的汽车子树。
- 真实库：升级日志 `结构变更前已备份: 20261113-185952_before-migration-v2.db`、`数据库结构版本: v1 -> v2`；升级后 1 笔工资流水（7936.68）与房租预算（3650）完好。
- OCR 建议实测：途虎养车→汽车›保养、汽车维修中心/更换刹车片→汽车›维修、平安车险→汽车›保险、中石化加油站→汽车›加油、万达停车场→汽车›停车费、滴滴出行→交通›打车、中国人寿→其他支出（未做通用保险规则，人工选人身险）。
