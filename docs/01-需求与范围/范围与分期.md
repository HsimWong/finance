# 范围与分期

## 目标

一个家庭自用的定制化财务平台：把收入与支出按**可细分领域**记录下来，并围绕「收入资金预先分配」做跟踪，最终能回答任意维度组合的查询。区别于通用记账软件的地方在于分类粒度、成员维度与预算跟踪是定制的。

## 使用者

- 家庭成员 2 人（姓名待确认，系统内以成员记录表示，可随时改名/增减）。
- 本机 / 家庭局域网内使用，不做公网暴露（默认假设）。

## 分期

### 一期：手动上传 + 记账主链路（本轮目标）

| 编号 | 能力 | 对应原始构想 |
| --- | --- | --- |
| F1 | 手动上传账单截图，截图保存在服务端 | 1、8 |
| F2 | 收支流水录入与编辑（成员、金额、时间、分类、标签、备注） | 2 |
| F3 | 细分领域分类树 + 跨领域标签 | 2、3 |
| F4 | 多维组合查询：成员 × 分类 × 标签 × 时间段 | 3 |
| F5 | 小荷包预分配（月初 / 月中）与预算完成进度 | 4、5 |
| F6 | 总览面板：收入资金使用情况与进度 | 6 |
| F7 | 报警表：未分类账单 | 7 |
| F8 | 截图 OCR 自动识别，结构化后自动填入录入表单（人工复核再落库） | 用户 2026-11-13 追加 |
| F9 | 家庭用品明细自动进入对应库存（瓜果蔬菜 / 肉蛋奶 / 粮油 / 调料 / 猫罐头 / 药品） | 用户追加 |
| F10 | 库存管理：每日消耗、手工入库、保质期、损耗、临期过期页面通报 | 原构想 10，提前实现 |
| F11 | 粘贴账单文字解析兜底（OCR 未就绪时仍可用） | 实现补充 |

### 二期：自动化与扩展

| 编号 | 能力 | 对应原始构想 |
| --- | --- | --- |
| F8 | 页面 / APK 自动获取账单 | 1 |
| F12 | 房租、保险等周期性费用的**微信推送**提醒 | 9 |

## 明确不做（一期）

- 不做移动端 APK、不做云同步、不做公网部署。
- 不做通用记账软件的账户体系（多账套、多币种、投资理财）。
- 不做微信推送 / 消息提醒（页面内临期过期通报已实现）。
- 不做 OCR 识别草稿的持久化与多人协同复核。

## 验收口径（一期）

1. 上传一张截图后，能在系统里生成一条可编辑的收支流水，截图原件可回看。
2. 能查到「某成员 / 某分类 / 某标签 / 某时间段」的合计金额。
3. 创建一笔预分配预算后，关联流水会实时反映已花 / 剩余 / 是否超额。
4. 未分类流水出现在报警表中，归类后自动消失。
5. `go run` 一条命令即可在本机启动，无需前端构建步骤。
6. 上传一张中文账单截图 → 自动识别出金额、时间与商品明细并填入表单 → 确认后生成流水，家庭用品同时出现在库存页。
7. 库存项可登记消耗与损耗，保质期临近或过期时库存页顶部出现通报。
