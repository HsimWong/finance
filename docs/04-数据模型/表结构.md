# 数据模型（一期）

金额统一 `INTEGER` 存**分**；时间统一存 ISO-8601 文本（`YYYY-MM-DDTHH:MM:SS` 或日期 `YYYY-MM-DD`），便于 SQLite 比较与前端直接使用。

## 关系概览

```
members ──┐
          ├──< entries >── categories        （主归类，树形）
categories┘        │
   ▲               ├──< entry_tags >── tags  （横向标签，多对多）
   └── parent_id    │
                    ├── allocations          （小荷包预分配）
                    └── screenshots          （截图原件 BLOB）
```

## 表定义

### members 家庭成员

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | |
| name | TEXT NOT NULL UNIQUE | 一期默认 2 人，占位名可改 |
| created_at | TEXT | |

### categories 细分领域分类树

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | |
| parent_id | INTEGER NULL | 父分类，NULL 为一级 |
| name | TEXT NOT NULL | 如 餐饮 / 外卖 / 交通 / 居住 |
| kind | TEXT | `expense` / `income` / `both` |
| sort_order | INTEGER | 展示顺序 |

约束：同一父节点下名称唯一。支出分类与收入分类用 `kind` 区分。

**当前种子分类树（v2，58 个节点）**：一级领域 18 个（餐饮 / 交通 / **汽车** / 居住 / 日用百货 / 医疗健康 / 宠物 / 保险 / 教育学习 / 娱乐休闲 / 人情往来 / 囤货采购 / 其他支出 + 6 个收入类），`汽车` 下为 `加油 · 停车费 · 保养 · 维修 · 保险`。

分类树变更走 `PRAGMA user_version` 版本化迁移（见 `src/backend/backup.go` 的 `migrations`），升级前强制备份；迁移只允许通过「改 `parent_id` / 改名 / 追加」调整结构，**不删有引用的行**，避免历史流水变成未分类。

| 字段 | 类型 | 说明 |

## 关键查询口径

- **未分类报警**：`WHERE category_id IS NULL`。
- **某成员外卖某段时间**：`member_id=? AND category_id IN (外卖及其子分类) AND occurred_at BETWEEN ? AND ?`。
- **全家交通支出**：展开「交通」分类子树后 `SUM(amount_cents)`。
- **猫咪花了多少**：`JOIN entry_tags WHERE tag_id=(猫咪)` 后 `SUM`；可与分类、时间自由叠加。
- **预算完成情况**：`SELECT SUM(amount_cents) FROM entries WHERE allocation_id=? AND type='expense'`，与 `budget_cents` 比较得出未动用 / 进行中 / 已用完 / 超额。

## 库存表（增量 2 已实现，独立模块，不混入 entries）

### stock_items 库存项

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | |
| name | TEXT | 物品名称（OCR 识别出的品名） |
| category_key / category_name | TEXT | 库存品类，如 `fruit_veg` / 瓜果蔬菜 |
| unit | TEXT | 盒、瓶、kg、袋… |
| qty | REAL | 当前数量（消耗/损耗会扣减） |
| amount_cents | INTEGER | 金额（分） |
| expiry_date | TEXT | 保质期至 `YYYY-MM-DD`，按品类默认天数预填 |
| status | TEXT | `in_stock` / `used_up` / `wasted` |
| entry_id | INTEGER NULL | 来源流水，`ON DELETE SET NULL` |
| auto_created | INTEGER | 1 = 账单识别自动生成；编辑/删除流水时只处理这类，手工录入项不受影响 |
| note / created_at / updated_at | TEXT | |

### stock_movements 出入库流水

`id` / `item_id`（级联删除）/ `kind`（`in` / `consume` / `waste`）/ `qty` / `note` / `created_at`。

索引：`entry_id`、`category_key`、`expiry_date`（临期查询用）。

**一致性**：创建流水与自动入库在**同一事务**；删除流水先删 `auto_created=1` 的关联库存项，避免外键置空后变成孤儿数据。
