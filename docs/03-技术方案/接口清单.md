# REST 接口清单（增量 1）

统一前缀 `/api`，响应统一为 `{"ok":true,"data":...}` / `{"ok":false,"error":"..."}`。
金额字段：请求用 `amount` / `budget`（单位「元」，字符串或数字），响应用 `xxx_cents`（整数分）+ `xxx`（元字符串）。
时间字段 `occurred_at` 用 `YYYY-MM-DDTHH:MM` 或 `YYYY-MM-DD`；后端会补秒以便排序。

## 基础数据

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/meta` | 一次性返回 members / categories / tags，前端初始化用 |
| POST | `/api/members` | `{name}` 新增成员 |
| PATCH | `/api/members/{id}` | `{name}` 改名 |
| DELETE | `/api/members/{id}` | 有流水时拒绝删除 |
| POST | `/api/categories` | `{parent_id, name, kind, sort_order}`，`kind`: expense/income/both |
| DELETE | `/api/categories/{id}` | 有子分类或被引用时拒绝删除 |
| POST | `/api/tags` | `{name}` 新增标签 |

## 截图

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/screenshots` | `multipart/form-data`，字段名 `file`，可选 `note`；≤10 MiB，图片字节入 SQLite BLOB |
| GET | `/api/screenshots` | 最近 200 张（不含图片数据），含 `has_entry` |
| GET | `/api/screenshots/{id}/image` | 回读原图，`Content-Type` 按实际 MIME |
| DELETE | `/api/screenshots/{id}` | 删除后流水关联自动置空 |

## 收支流水

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/entries` | 支持 `type / member_id / category_id / tag_id / allocation_id / from / to / q / uncategorized / include_subtree / limit / offset`；返回 `items / total / sum` |
| POST | `/api/entries` | 见下方请求体 |
| GET | `/api/entries/{id}` | 单条详情（含 tags） |
| PUT | `/api/entries/{id}` | 全量更新（字段同 POST） |
| PATCH | `/api/entries/{id}/classify` | `{category_id, tag_ids}` 仅归类，报警表用 |
| DELETE | `/api/entries/{id}` | 级联删除标签关联 |
| GET | `/api/alerts` | 未分类流水 + 总数 |

`POST /api/entries` 请求体：

```json
{
  "type": "expense",
  "amount": "35.50",
  "occurred_at": "2026-11-13T12:30",
  "member_id": 1,
  "category_id": 2,
  "allocation_id": 1,
  "screenshot_id": 1,
  "source": "screenshot",
  "note": "猫咪罐头",
  "tag_ids": [1, 3]
}
```

`category_id` 为 `null` 即未分类，会进入报警表。`source` 取值 `manual` / `screenshot` / `auto`（二期）。

## 预算

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/allocations` | 可按 `period=YYYY-MM` 过滤；含 `spent / remaining / progress / status` |
| POST | `/api/allocations` | `{period, batch, name, category_id, budget, note}` |
| PUT | `/api/allocations/{id}` | 全量更新 |
| DELETE | `/api/allocations/{id}` | 关联流水解除预算 |

`batch`: `first`（月初）/ `mid`（月中）。`status`: 未动用 / 进行中 / 已用完 / 超额。

## 报表与总览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/report` | `group_by`: category（顶级领域汇总）/ category_detail / member / tag / month / day；可叠加所有流水筛选条件 |
| GET | `/api/dashboard` | `period=YYYY-MM`；返回收入、支出、结余、已分配、已使用、剩余、分配率、使用率、未分类数、预算列表、领域分布、最近流水 |

## 已验证的关键口径

- 「A 人员外卖某段时间」→ `member_id` + `category_id`（可 `include_subtree=1`）+ `from/to`。
- 「全家交通支出」→ `report?group_by=category` 会把「交通」下所有子分类汇总到顶级领域。
- 「猫咪花了多少」→ `report?group_by=tag` 或 `entries?tag_id=...`。
- 「预分配 4000 房租是否花掉」→ `allocations` 中 `spent / status / progress`。

## OCR 识别（增量 2）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/ocr/status` | `{available, engine, hint}`，启动时自检结果 |
| POST | `/api/ocr/recognize` | 二选一：`{"screenshot_id": 2}` 对已上传截图识别；或 `multipart/form-data` 直接传 `file`（内部先保存截图）。返回识别草稿，不写流水 |
| POST | `/api/ocr/parse-text` | `{"text": "...", "screenshot_id": 0}`，粘贴文字兜底，复用同一套解析规则 |

`recognize` / `parse-text` 返回统一结构：

```json
{
  "screenshot_id": 2,
  "engine": "RapidOCR(onnxruntime)",
  "raw_text": "永辉超市\n鸡蛋 1盒 12.50\n实付¥65.40",
  "lines": [{"text": "鸡蛋 1盒 12.50", "score": 0.76, "box": [...]}],
  "suggestion": {
    "type": "expense", "amount": "65.40", "amount_cents": 6540,
    "occurred_at": "2026-11-13T18:24", "merchant": "超市 / 生鲜",
    "category_id": 45, "category_name": "囤货采购",
    "tag_ids": [5], "note": "超市 / 生鲜 · 含家庭用品 5 项",
    "field_confidence": {"amount": 0.9, "occurred_at": 0.95, "type": 0.85, "category": 0.85}
  },
  "items": [{
    "name": "鸡蛋", "qty": 1, "unit": "盒", "amount": "12.50", "amount_cents": 1250,
    "category_key": "meat_egg_milk", "category_name": "肉蛋奶",
    "expiry_date": "2026-11-27", "is_household": true, "confidence": 0.75
  }],
  "confidence": 0.9,
  "warnings": ["识别到 5 项家庭用品，确认后将自动入库…"],
  "error": ""
}
```

`error` 非空表示 OCR 未就绪或识别失败，此时 `screenshot_id` 仍有效，可改用粘贴文本。
`GET /api/meta` 额外返回 `stock_rules`（品类 key、名称、默认保质期天数）。

### 自动入库

`POST /api/entries` 请求体新增可选 `stock_items`：

```json
"stock_items": [
  {"name":"鸡蛋","qty":1,"unit":"盒","amount":"12.50",
   "category_key":"meat_egg_milk","category_name":"肉蛋奶","expiry_date":"2026-11-27"}
]
```

- 字段**缺省**：不改动库存；字段为**空数组**：清空该流水的自动生成项。
- `PUT /api/entries/{id}` 同样支持；`DELETE /api/entries/{id}` 会先清理关联自动入库项。

## 库存（增量 2）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/stock/summary` | 品类汇总 + 在库总数/金额 + 过期/临期数量 + 通报明细 |
| GET | `/api/stock/items` | 明细，支持 `category_key / status / q / expiring`；含 `days_left`、`expiry_status`（`soon`/`expired`）、`auto_created` |
| POST | `/api/stock/items` | 手工入库，品类留空时按名称自动判断 |
| PUT | `/api/stock/items/{id}` | 编辑名称/数量/单位/金额/保质期/状态/备注 |
| DELETE | `/api/stock/items/{id}` | 级联删除出入库记录 |
| POST | `/api/stock/items/{id}/consume` | `{"qty":0.5,"note":""}` 每日消耗；扣到 0 自动 `used_up` |
| POST | `/api/stock/items/{id}/waste` | 同上，扣到 0 自动 `wasted` |
| GET | `/api/stock/movements` | 出入库记录，可按 `item_id` 过滤 |
